# Hydr'eau

Le projet Hydr'eau à pour but de proposer une centralisation et homogénéisation des données de l'hydraulique agricole en Provence-Alpes-Côte d'Azur. les détails d'Hydr'eau sont accessibles via cette url : https://www.crige-paca.org/projet/bd-hydreau/#presentation

Cette page permet de centraliser les livrables opérationnels du projet à savoir :
- le MCD
- le dictionnaire de données
- la nomenclature et les fichiers de styles proposés
- les fichiers geopackages d'exemple
